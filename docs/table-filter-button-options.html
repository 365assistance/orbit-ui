Table filter button: two options

You liked TableCard and want a variation that combines multiple filters into one filter button instead of a row of separate dropdowns. Here are the two common patterns, both on the TableCard you already have. Pick one and I'll build it into the library.

Option 1, one Filters button with a count, opens a panel

A single "Filters" button shows how many filters are active (the badge). Clicking it opens a panel holding every filter in one place, with Apply and Reset. Active filters also show as removable chips above the table so they stay visible. This is the standard pattern for data-dense tables with several filters.

Best when there are 3+ filters. The count and the chip row keep active filters visible even though the controls are tucked away.

Option 2, one dropdown that holds multiple filter sections

A single "Filter" dropdown that, when opened, lists each filter as its own section inline (no separate panel, no Apply step, it filters as you pick). Lighter weight than the panel. Good when there are only two or three simple filters.

My recommendation: Option 1 (Filters button + count + panel + removable chips). It scales as filters grow, keeps active filters visible, and matches the data-dense finance tables. Option 2 is nicer only when you are sure it stays at two or three simple filters.
